# Página de Login - Projeto de Estudo

Este é um projeto simples de página de login, desenvolvido como parte de uma vídeo aula para praticar **HTML** e **CSS**.

## 💡 Objetivo

O principal objetivo foi colocar em prática conceitos básicos de marcação com HTML e estilização com CSS, como:
- Estrutura de formulários
- Uso de classes e `id`
- Layout com flexbox (se aplicável)
- Estilização de botões, inputs e responsividade básica

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
